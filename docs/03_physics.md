# 03. 물리 공식과 계산 방법

이 문서는 프로그램이 사용하는 물리 공식과 그 근거를 정리한다.
여기 있는 내용은 학술적으로 규명된 것이므로 사용자에게 묻지 않고 그대로 적용한다.
단, 어떤 모델을 쓸지(등속 / 가속)는 사용자 결정 사항이며 [06_decisions.md](06_decisions.md)에 기록되어 있다.

## 1. 기본 상수

| 기호 | 값 | 설명 |
|---|---|---|
| c | 299,792,458 m/s | 진공 중 빛의 속도 (정의값, SI) |
| AU | 149,597,870,700 m | 천문단위 (IAU 2012 정의값) |
| ly | 9,460,730,472,580,800 m | 광년 (율리우스년 365.25일 × c) |
| 1년 | 365.25일 = 31,557,600 s | 율리우스년. 시간 표시 단위로 사용 |
| g | 9.80665 m/s² | 표준 중력가속도 (가속 모델에서 사용) |

## 2. 등속 비행 모델 (1차 구현)

우주선이 출발 직후부터 일정한 속도 v로 거리 d를 이동한다고 가정한다.

### 2.1 로런츠 인자

```
β = v / c
γ = 1 / √(1 − β²)
```

- v = 11.2 km/s일 때 β ≈ 3.7 × 10⁻⁵, γ ≈ 1 + 7 × 10⁻¹⁰
- v = 0.99c일 때 γ ≈ 7.09

### 2.2 지구 기준 경과 시간 (좌표 시간)

```
t_지구 = d / v
```

### 2.3 우주선 기준 경과 시간 (고유 시간)

```
τ_우주선 = t_지구 / γ = (d / v) × √(1 − β²)
```

### 2.4 시간 차이

```
Δt = t_지구 − τ_우주선
```

### 2.5 왕복

등속 모델에서는 방향 전환에 걸리는 시간을 0으로 보고, 편도 결과에 2를 곱한다.

```
t_지구(왕복) = 2 × d / v
τ_우주선(왕복) = 2 × (d / v) / γ
```

## 3. 수치 계산 시 주의 사항

### 3.1 낮은 속도에서의 정밀도

v = 11.2 km/s처럼 β가 매우 작으면 γ − 1 ≈ 7 × 10⁻¹⁰이다.
`1 / Math.sqrt(1 - β*β) - 1`로 직접 계산하면 1에 가까운 수끼리 빼면서 유효숫자를 잃는다.
따라서 β가 작을 때(예: β < 10⁻³)는 테일러 급수를 사용한다.

```
γ − 1 ≈ β²/2 + 3β⁴/8 + 5β⁶/16
```

시간 차이 Δt도 같은 이유로 `t_지구 − τ_우주선`을 직접 빼지 않고 다음 식으로 계산한다.

```
Δt = t_지구 × (1 − 1/γ)
1 − 1/γ = 1 − √(1 − β²) ≈ β²/2 + β⁴/8 + β⁶/16   (β가 작을 때)
```

### 3.2 큰 수 처리

안드로메다(약 250만 광년)까지 11.2 km/s로 가면 지구 시간은 약 6.7 × 10¹⁰년이다.
JavaScript의 Number(배정밀도 실수)는 약 1.8 × 10³⁰⁸까지 표현하므로 초 단위로 계산해도 문제없다.
다만 화면 표시 시 자릿수가 많으므로 [utils](../src/utils/README.md)의 서식 함수로 단위를 자동 조정한다.

### 3.3 발사장 위치가 계산에 미치는 영향

지구 반지름은 약 6,371 km이고, 가장 가까운 목적지인 달까지의 거리는 약 384,400 km이다.
발사장 위치에 따른 거리 차이는 최대 지구 지름 수준(약 12,700 km)으로 달 거리의 약 3%이며,
화성 이상의 목적지에서는 0.01% 미만이다.
따라서 발사장 선택은 거리 계산에 반영하지 않고, 출발 지점 표시 용도로만 사용한다.
(이 결정은 물리적 근거에 따른 것이며 [06_decisions.md](06_decisions.md)에도 기록한다.)

## 4. 가속-감속 모델 (후순위 구현)

우주선이 고유 가속도 a로 여행 거리의 절반까지 가속한 뒤, 같은 크기로 감속하여 목적지에 정지한다고 가정한다.
상대론적 등가속 운동(쌍곡선 운동)의 공식을 사용한다.

거리 x를 정지 상태에서 고유 가속도 a로 가속하며 이동할 때:

```
지구 시간   t(x) = √( (x/c)² + 2x/a )
우주선 시간 τ(x) = (c/a) × acosh( 1 + a·x / c² )
최고 속도   v_max = a·t / √(1 + (a·t/c)²)
```

편도(가속 절반 + 감속 절반), x = d/2:

```
t_지구(편도) = 2 × t(d/2)
τ_우주선(편도) = 2 × τ(d/2)
```

왕복은 편도의 2배이다.

이 모델에서는 입력 변수가 "속도"가 아니라 "가속도"가 되므로,
슬라이더 구성이 등속 모델과 달라진다. 구현 전에 사용자에게 확인한다.

## 6. 발사 시뮬레이션 물리 (기능 1, 10~13단계)

발사 장면의 로켓 운동은 아래 공식으로 계산한다. 공기 저항은 사용자 결정(D-21)에 따라 생략한다.
이 절의 물리는 시간 지연 계산(2절)과 독립이다.

### 6.1 추가 상수

| 기호 | 값 | 설명 |
|---|---|---|
| GM (지구) | 3.986004418 × 10¹⁴ m³/s² | 지구 표준 중력 매개변수 (WGS 84) |
| R (지구 반지름) | 6,371,000 m | 평균 반지름 |
| g₀ | 9.80665 m/s² | 비추력 정의에 쓰는 표준 중력가속도 |

### 6.2 운동 방정식

위치 벡터 r, 속도 벡터 v, 질량 m(t), 추력 크기 T, 추력 방향 단위벡터 u에 대해:

```
dv/dt = (T / m) · u − (GM / |r|²) · (r / |r|)
dr/dt = v
dm/dt = − T / (Isp · g₀)          (엔진 연소 중)
```

- Isp(비추력, 초)는 단마다 다르며 [05_data_reference.md](05_data_reference.md) 6절의 값을 쓴다.
- 추력 방향 u는 발사 직후 수직이고, 일정 시간 후 서서히 기울이는 **피치 프로그램**을 따른다.
  피치 프로그램의 구체적 각도 곡선은 물리 법칙이 아니라 조정 가능한 매개변수이며, 구현 시 사용자와 확인한다 (Q-14).

### 6.3 단 분리

각 단은 자기 추진제를 모두 소모한 순간 분리된다. 분리 직후 분리된 부분과 남은 부분은
**같은 위치, 같은 속도**를 가지며, 이후 각자 운동 방정식을 따른다. (분리 시 밀어내는 힘은 무시)

팔콘 헤비형 분리 순서와 분리 시점의 질량:

```
발사 시          m = 부스터×2 + 코어 + 2단 + 탑재체
부스터 분리 후   m = 코어(남은 추진제) + 2단 + 탑재체
코어 분리 후     m = 2단 + 탑재체
2단 분리 후      m = 탑재체(우주선)
```

### 6.4 검증: 치올콥스키 로켓 방정식

중력이 없는 경우 한 단이 낼 수 있는 속도 증분:

```
Δv = Isp · g₀ · ln(m₀ / m_f)
```

수치 적분 결과는 중력 손실 때문에 이 값보다 작아야 하며, 중력을 0으로 놓고 적분하면 이 값과 일치해야 한다.
이 성질을 `tests/`의 검증 항목으로 사용한다.

### 6.5 재착륙 안내 (단순화)

분리된 부스터와 코어는 다음 세 구간으로 착륙한다.

1. **부스트백 연소**: 수평 속도를 반대로 바꿔 착륙 지점 방향으로 향하게 한다. (부스터: 발사장 근처 착륙장, 코어: 진행 방향 앞쪽 무인선)
2. **자유 낙하**: 엔진을 끄고 중력만 받으며 떨어진다.
3. **착륙 연소**: 지면에 속도 0으로 닿도록 일정 감속도 a로 감속한다.

착륙 연소를 시작해야 하는 고도 h는 속도 v, 감속도 a, 중력가속도 g에 대해:

```
h = v² / ( 2 · (a − g) )        (a > g)
```

실제 유도 알고리즘은 훨씬 복잡하지만, 사용자 결정(D-21 단순 물리)에 맞춰 이 수준으로 구현한다.
수평 방향 오차는 부스트백 연소량을 착륙 지점까지의 거리에 맞춰 조정하는 방식으로 처리한다.

### 6.6 시간 적분

- 고정 시간 간격 Δt(예: 1/60초)로 **반음해 오일러**(속도를 먼저 갱신하고 그 속도로 위치 갱신) 또는 **RK4**를 사용한다.
- 배속 N배는 한 화면 프레임마다 적분을 N번 수행하여 구현한다.
- 지면 충돌: |r| < R 이면 지면에 닿은 것으로 보고 속도를 0으로 만든다. 착륙 연소가 제대로 되면 닿는 순간의 속도가 작아야 한다.
