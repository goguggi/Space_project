# 04. 단계별 개발 계획

전체 기능을 한 번에 만들지 않고 아래 순서대로 구현한다.
각 단계는 "완료 조건"을 만족하면 끝나며, 끝날 때마다 Git에 커밋하고
해당 폴더의 README.md와 [INDEX.md](INDEX.md)를 갱신한다.

진행 순서는 **1 → 2 → 3 → 4 → 5 → 6 → 7 → 10 → 11 → 12 → 13 → 14 → 15 → 8 → 9** 이다. (D-28)
단계 번호는 처음 계획한 번호를 유지하고, 순서만 바꾼다.

## 0단계: 계획 수립 (완료)

- 요구사항 정리, 물리 근거 문서, 폴더 골격, Git 초기화

## 1단계: 출발 위치(발사장) 선택

**만드는 것**
- `index.html` 진입점
- `src/data/launchSites.js`: 발사장 5곳의 이름, 국가, 위도, 경도
- `src/ui/launchSiteSelector.js`: 발사장 선택 메뉴, 선택한 발사장 정보 표시
- `src/styles/main.css`: 기본 화면 스타일

**완료 조건**
- 브라우저에서 열었을 때 발사장 5곳이 목록에 보인다.
- 하나를 선택하면 이름, 국가, 위도, 경도가 화면에 표시된다.

**적용할 결정**
- ES 모듈로 작성, 로컬 서버로 확인 (D-27). 저장소 최상위의 `index.html`이 GitHub Pages 진입점 (D-46)

## 2단계: 목적지(천체) 선택

**만드는 것**
- `src/data/destinations.js`: 천체 12개의 이름, 구분, 지구로부터의 평균 거리(m), 출처
- `src/data/constants.js`: c, AU, ly 등 물리 상수
- `src/utils/units.js`: km / AU / 광년 ↔ m 변환
- `src/ui/destinationSelector.js`: 구분별로 묶인 천체 선택 메뉴, 선택한 천체의 거리 표시

**완료 조건**
- 천체 12개가 구분(태양계 / 근처 별 / 은하 규모 / 은하 밖)별로 보인다.
- 선택하면 거리가 적절한 단위(km, AU, 광년)로 표시된다.

## 3단계: 속도 슬라이더와 로런츠 인자 표시

**만드는 것**
- `src/data/rockets.js`: 하한 기준값(팔콘 헤비 지구 탈출 속도 11.2 km/s), 상한(0.99c), 프리셋 6개(보이저 1호, 파커 탐사선, 0.1c, 0.5c, 0.9c, 0.99c)와 출처
- `src/physics/lorentz.js`: β, γ 계산 (낮은 속도용 급수 포함)
- `src/ui/speedSlider.js`: 로그 눈금 속도 슬라이더(11.2 km/s ~ 0.99c), 현재 속도를 km/s와 광속 비율로 표시
- `src/ui/speedPresets.js`: 프리셋 버튼 6개. 누르면 슬라이더가 해당 속도로 이동
- `src/ui/lorentzDisplay.js`: 속도에 대응하는 로런츠 인자를 표시 전용 슬라이더 형태로 표시

**완료 조건**
- 슬라이더를 움직이면 속도와 γ가 즉시 갱신된다.
- 프리셋 버튼을 누르면 슬라이더와 γ가 해당 값으로 이동한다.
- [03_physics.md](03_physics.md) 5절의 기준값과 일치한다.

**적용할 결정**
- 로그 눈금 (D-29), γ 슬라이더 표시 전용 (D-30), 프리셋 6개 (D-36)

## 4단계: 시간 지연 계산 엔진

**만드는 것**
- `src/physics/timeDilation.js`: 거리, 속도, 편도/왕복을 받아 지구 시간, 우주선 시간, 차이를 초 단위로 반환
- `src/ui/tripTypeSelector.js`: 편도 / 왕복 선택
- `tests/physics.test.html`: 기준값 검증 페이지

**완료 조건**
- 검증 페이지의 모든 기준값이 통과한다.

## 5단계: 결과 수치 표

**만드는 것**
- `src/utils/formatTime.js`: 초 → 년/일/시/분/초 변환과 큰 수 서식
- `src/ui/resultTable.js`: 지구 시간 / 우주선 시간 / 차이 표

**완료 조건**
- 발사장, 목적지, 속도, 편도/왕복을 바꾸면 표가 즉시 갱신된다.

## 6단계: 스톱워치 애니메이션

**만드는 것**
- `src/ui/stopwatch.js`: `0년 0일 0시 0분 0초`에서 결과값까지 올라가는 애니메이션. 지구 시간과 우주선 시간 두 개를 나란히 표시

**완료 조건**
- 발사 장면 종료 후(발사 장면이 아직 없는 동안은 계산 직후) 두 스톱워치가 자동으로 시작해 각자 결과값까지 올라가고 멈춘다.
- 결과가 길수록 애니메이션이 길다. 3초(가장 짧은 결과)에서 15초(가장 긴 결과) 사이.
- 100만 년 이상은 "만 년", "억 년" 단위로 표시된다.

**적용할 결정**
- 자동 시작, 3~15초 (D-31), 년/일/시/분/초 (D-32)

## 7단계: 생물 수명 비교

**만드는 것**
- `src/data/organisms.js`: 생물 5종의 이름, 대표 수명(초), 출처
- `src/ui/departureAgeInput.js`: 생물별 출발 시점 나이 입력란 (기본값 0)
- `src/ui/lifespanChart.js`: HTML/CSS div 막대, 로그 눈금. 생물별 수명 막대 위에 지구 시간과 우주선 시간을 겹쳐 그림
- `src/ui/survivalIcons.js`: 생물별 우주선 탑승 시 / 지구 잔류 시 도착 시점 생존 여부 아이콘. 판정: 출발 나이 + 경과 시간 < 수명이면 생존

**완료 조건**
- 5종 모두에 대해 그래프와 아이콘이 표시되고, 입력(출발 나이 포함)을 바꾸면 갱신된다.

**적용할 결정**
- 출발 나이 사용자 입력 (D-33), div 막대 (D-34), 하루살이 성충 1일 (D-37), 사람 80년 (D-38)

## 8단계: 가속-감속 모델 (발사 시뮬레이션 뒤에 진행)

**만드는 것**
- `src/physics/acceleratedMotion.js`: [03_physics.md](03_physics.md) 4절의 공식, 가속도는 1g 고정
- `src/ui/motionModelSelector.js`: 등속 / 가속-감속(1g) 선택

**완료 조건**
- 가속-감속을 고르면 지구 시간, 우주선 시간, 최고 속도가 1g 기준으로 계산되어 표와 스톱워치에 반영된다.

**적용할 결정**
- 가속도 1g 고정, 슬라이더 없음 (D-35)

**적용할 결정**

## 11단계: 로켓 모델과 발사 물리 (단 분리 없음)

**만드는 것**
- `src/data/falconHeavy.js`: 각 단의 질량, 추력, 비추력, 연소 시간. **형식은 [08_rocket_design_handoff.md](08_rocket_design_handoff.md) 6절의 `stages[]`와 동일**하게 만든다 (16단계에서 설계 로켓으로 교체하기 위함)
- `src/physics/launchDynamics.js`: [03_physics.md](03_physics.md) 6.2절과 6.6절. 입력은 `stages[]` 형식
- `src/launch/rocketModel.js`: 로켓 형상(원통 + 원뿔)과 화염
- `src/launch/followCamera.js`: 로켓 뒤를 따라가는 3인칭 카메라
- `src/launch/launchTimeline.js`: 발사 시작, 경과 시간, 배속(1~10배)
- `src/ui/launchButton.js`: "발사" 버튼

**완료 조건**
- 발사 버튼을 누르면 로켓이 상승하고 카메라가 따라간다. 배속을 바꾸면 빨라진다.
- 중력을 0으로 놓고 계산하면 치올콥스키 방정식 값과 일치한다 (tests에 추가).

**적용할 결정**
- 피치 프로그램: 발사 10초 후부터 약 2분간 서서히 수평 쪽으로 (D-40), 탑재체 10 t (D-43)

## 12단계: 단 분리

**만드는 것**
- `src/physics/staging.js`: 추진제 소진 시 분리, 분리 후 초기 상태
- `rocketModel.js` 확장: 부스터 2기, 코어, 2단을 별도 물체로 분리 표현

**완료 조건**
- 측면 부스터 → 코어 → 2단 순서로 분리되고, 분리된 부분이 관성으로 계속 움직인다.
- 분리 시점이 [03_physics.md](03_physics.md) 6.7절 기록과 같은 자릿수이다.

## 14단계: 화면 분할 카메라와 HUD

**만드는 것**
- `src/launch/pipView.js`: 착륙 장면용 보조 화면
- `src/launch/launchHud.js`: 경과 시간, 고도, 속도, 현재 단계, 배속 조절, 건너뛰기 버튼

**완료 조건**
- 분리 후 주 화면은 2단을, 보조 화면은 착륙 중인 부스터/코어를 보여준다.
- 건너뛰기를 누르면 즉시 발사 장면이 끝난다.

**적용할 결정**
- 보조 화면 1개, 가장 가까운 착륙 대상으로 자동 전환 (D-42)

## 15단계: 발사 장면과 결과 화면 연결

**만드는 것**
- 2단 분리 후 "우주선이 지정 속도로 출발"하는 전환 연출
- 기존 스톱워치(6단계)와 결과 화면(5, 7단계)으로 자연스럽게 이동

**완료 조건**
- 발사 → 분리 → 착륙 → 출발 → 스톱워치 → 결과의 흐름이 끊김 없이 이어진다.

## 16단계: 설계한 로켓 불러오기 (기능 2)

**만드는 것**
- `src/data/rocketSpecSchema.js`: JSON 형식의 필수 필드 정의
- `src/physics/rocketSpecValidator.js`: [08_rocket_design_handoff.md](08_rocket_design_handoff.md) 5절 검증 규칙 V-01~V-07
- `src/ui/rocketFileLoader.js`: "설계한 로켓 불러오기" 버튼, 파일 선택, 한국어 오류 안내
- `src/launch/rocketModel.js` 확장: `geometry.parts`로 로켓 형상 생성
- `src/physics/staging.js` 일반화: 임의의 병렬/직렬 단 구성과 회수 설정 처리

**완료 조건**
- [examples/falcon_heavy.rocket.json](examples/falcon_heavy.rocket.json)을 불러오면 기본 팔콘 헤비와 같은 발사 장면이 재생된다.
- 설계 프로그램이 내보낸 다른 구성의 로켓도 재생된다.
- 잘못된 파일(필드 누락, TWR < 1 등)은 발사 버튼이 비활성화되고 이유가 표시된다.

**적용할 결정**
- JSON 파일 방식 (D-48). 예비 추진제 비율 기본 5% (Q-20 확정 후)
