# 05. 기초 데이터와 출처

프로그램이 사용하는 모든 수치의 근거를 여기에 모은다.
`src/data/`의 코드 파일에 값을 넣을 때는 반드시 이 문서와 일치시키고, 출처를 주석으로 남긴다.
"확인 필요"로 표시된 값은 코드에 넣기 전에 원 출처를 다시 확인한다.
