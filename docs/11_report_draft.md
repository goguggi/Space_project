## Ⅰ. 탐구(연구) 동기

### 1. "시간이 느리게 간다"는 말은 왜 와닿지 않는가

빛의 속도는 누가 재도 똑같다는 광속 불변 원리에서, 빠르게 움직이는 관측자의 시간이 느리게 흐른다는 시간 지연이 나온다. "우주여행을 다녀오면 지구 사람들이 더 늙어 있다"는 이야기는 영화로 널리 알려져 있지만, 그 크기가 얼마인지는 γ = 1/√(1 − v²/c²)라는 식 한 줄로 요약될 뿐 숫자만 봐서는 감이 오지 않는다.

우리는 이미 움직이고 있다. 지구 자전만으로도 적도에서 465 m/s(마하 1.4), 지구 공전은 29.8 km/s다. 그런데도 시간 지연을 느끼지 못한다. 반대로 광속의 99 %에서는 지구 7년이 우주선 1년이다. 이 두 극단 사이에서 시간 지연이 어떻게 변하는지를 한 화면에서 비교해 보고 싶었다.

### 2. 계산기가 아니라 "여행"으로 만든다

시간 지연을 "몇 초 차이"가 아니라 "하루살이 수명의 몇 배", "사람 수명의 몇 %"로 바꾸면 크기가 곧바로 와닿는다. 그래서 수명이 1일(하루살이)부터 400년(그린란드 상어)까지 걸치는 생물 5종을 자로 삼았다. 또 Kerbal Space Program(KSP)처럼 로켓이 발사장에서 떠올라 단이 분리되고 스페이스X 방식으로 재착륙하며, 우주선이 목적지까지 항행해 착륙하는 과정을 3D로 지켜보게 하면 시간 지연이 하나의 "임무"로 느껴진다.

## Ⅱ. 탐구(연구) 내용 및 과제

### 1. 탐구 목표

지구의 발사장에서 출발한 우주선이 특정 천체까지 이동할 때, 속도와 거리에 따른 상대론적 시간 지연을 계산하고, 그 결과를 여러 생물의 수명과 비교하여 직관적으로 이해하게 하는 웹 프로그램을 개발한다.

### 2. 세부 과제

#### 가. 시간 지연 계산기 (핵심)

발사장 5곳, 목적지 천체 12개(달~안드로메다), 속도(11.2 km/s ~ 0.99c), 편도/왕복을 입력받아 지구 시간·우주선 시간·차이를 계산하고, 수치 표, 스톱워치 애니메이션, 생물 5종 수명 대비 막대 그래프, 생존 여부 아이콘으로 보여 준다.

#### 나. 3D 로켓 발사 시뮬레이션

팔콘 헤비형 로켓(측면 부스터 2기 + 중앙 코어 + 2단)을 뉴턴 운동 법칙으로 발사한다. 배기가스를 뒤로 밀어낸 반작용(3법칙)이 추력이 되고, 추력·중력·줄어드는 질량으로 매 순간의 가속도를 구해(2법칙) 1/60초마다 속도와 위치를 갱신한다. 부스터는 착륙장, 코어는 무인선에 자동 유도로 재착륙하며, 3인칭 추적 카메라와 착륙 보조 화면, 배속·건너뛰기를 제공한다.

#### 다. 우주 항행·착륙·탐사 장면

달부터 안드로메다까지 서로 다른 거리 규모의 천체를 같은 코드로 그리고, 광행차와 도플러 효과를 실제 공식으로 별 배경에 적용한다. 달·화성·지구에 착륙하며 KSP식 착륙 절차와 실패(파손) 판정을 두고, 착륙 후 우주인이 지표를 탐사한 뒤 이륙해 귀환한다.

### 3. 탐구 범위와 제한

시간 지연은 등속 직선 비행의 특수 상대성 효과만 계산하고 중력 시간 지연은 다루지 않는다. 행성 거리는 평균 거리 하나로 고정하고, 발사 물리에서 공기 저항과 지구 자전은 생략한다. 외부 라이브러리는 3D 장면의 Three.js 하나만 쓴다.

## Ⅲ. 이론적 배경 및 사전 조사

### 1. 로런츠 인자와 시간 지연

#### 가. 빛 시계로 보는 시간 지연

우주선 바닥에서 위로 빛을 쏘아 천장의 거울에 반사되어 돌아오는 빛 시계를 생각한다. 우주선 안 사람에게 한 번 똑딱하는 시간은 τ = 2L / c 다. 지구에서 보면 우주선이 속도 v로 옆으로 움직이므로 빛은 비스듬한 지그재그 경로를 지난다. 경로가 길어졌는데 빛의 속도는 여전히 c이므로 지구에서 본 똑딱 시간 t는 τ보다 길다. 피타고라스 정리로 정리하면 t = τ / √(1 − v²/c²) 이다. 우주선 안의 시계가 지구 시계보다 느리게 가는 것, 이것이 시간 지연이다.

#### 나. 로런츠 인자 γ

```
β = v / c            (광속에 대한 속도의 비율)
γ = 1 / √(1 − β²)    (γ ≥ 1)
```

지구에서 흐른 시간 = γ × 우주선에서 흐른 시간. 즉 γ는 "지구 시간이 우주선 시간의 몇 배인가"다.

| 속도 | β | γ | 뜻 |
|---|---|---|---|
| 11.2 km/s (지구 탈출 속도) | 0.000037 | 1.0000000007 | 사실상 차이 없음 |
| 광속의 50 % | 0.5 | 1.155 | 15 % 느려짐 |
| 광속의 90 % | 0.9 | 2.294 | 지구 시간이 우주선의 2.3배 |
| 광속의 99 % | 0.99 | 7.089 | 지구 7년 = 우주선 1년 |

β가 0.5까지는 γ가 1.15밖에 안 되지만 0.9를 넘어서면 급격히 커지고, 1에 가까워질수록 무한대로 치솟는다. 시간 지연이 일상에서는 느껴지지 않다가 광속 근처에서만 폭발적으로 커지는 이유가 이 곡선의 모양에 있다. 프로그램은 속도 슬라이더 아래에 이 곡선을 그리고 현재 속도를 점으로 표시한다.

### 2. 광행차 (빛의 방향이 앞으로 쏠리는 현상)

바람 없는 날 비가 수직으로 내려도 달리면 앞에서 비스듬히 오는 것처럼 느껴진다. 별빛도 마찬가지로, 우주선이 빨라질수록 별들이 진행 방향 앞쪽으로 몰려 보인다.

#### 가. 머리 위의 별: 교과서의 광행차 공식

별빛은 속도 c로 수직으로 내려오고 우주선은 속도 v로 나아가므로, 두 속도를 벡터로 더하면 빛이 오는 것처럼 보이는 방향이 앞쪽으로 기운다. 그 방향이 진행 방향과 이루는 각 θ는

```
tan θ = c / v
```

이다. v가 작으면 θ ≈ 90°로 머리 위 그대로이고, v가 커질수록 별이 앞쪽으로 내려온다. 지구 공전 속도(29.8 km/s) 때문에 별의 위치가 1년 주기로 약 20″씩 흔들리는데, 1727년 브래들리가 이를 관측해 광행차를 발견했다.

#### 나. 어느 방향의 별이든: 일반형

별이 진행 방향과 각도 θ에 있을 때 우주선에서 보이는 각도 θ′는

```
cos θ′ = (cos θ + β) / (1 + β cos θ)
```

이다. 상대성 이론의 속도 덧셈으로 구한 식이라 광속에 가까운 속도까지 쓸 수 있고, 머리 위의 별에 v ≪ c를 넣으면 tan θ = c/v와 같아진다.

| 우주선 속도 | 교과서 식 | 일반형 |
|---|---|---|
| 30 km/s (지구 공전) | 89.994° | 89.994° |
| 광속의 50 % | 63.4° | 60.0° |
| 광속의 99 % | 45.3° | 8.1° |

일상 속도에서는 두 식이 같지만 광속의 절반을 넘으면 차이가 커지므로 프로그램은 일반형을 쓴다. 광속의 90 %를 넘으면 별이 앞쪽으로 뚜렷하게 모이고, 도플러 효과로 앞쪽 별은 파랗게 뒤쪽 별은 붉게 물든다.

### 3. 여행 시간을 구하는 두 가지 모델

#### 가. 등속 비행 모델 (프로그램의 기본 모델)

출발하자마자 속도 v로 일정하게 거리 d를 간다고 가정한다. 왕복은 편도의 2배다.

```
지구 시간 t = d / v,   우주선 시간 τ = t / γ,   차이 Δt = t − τ
```

예) 프록시마 센타우리(4.246광년)까지 광속의 99 %로 편도: t = 4.29년, τ = 4.29 ÷ 7.089 = 0.605년(약 221일). 우주선에 탄 사람은 3년 8개월 덜 늙는다.

#### 나. 가속-감속 모델 (후속 구현 예정)

거리의 절반까지 1g로 가속하고 나머지를 감속한다고 가정한다. 뉴턴 역학의 v = a·t 대로면 1g로 1년만 가속해도 광속을 넘어 버리지만, 상대성 이론에서는 c에 가까워질수록 속도가 잘 늘지 않는다. 거리 x를 가속도 a로 가는 시간은

```
지구 시간 t = √( (x/c)² + 2x/a ),   우주선 시간 τ = (c/a) · acosh( 1 + a·x/c² )
```

이고 x = d/2를 넣어 2배 한다. 예) 1g로 프록시마까지 편도: 지구 5.9년, 우주선 3.5년, 최고 속도는 광속의 약 95 %다.

### 4. 계산에 쓴 수학 개념 (간단히)

- 미분(순간 변화율): 위치의 순간 변화율이 속도, 속도의 순간 변화율이 가속도. 발사 장면에서 매 순간의 가속도를 (추력 − 중력) ÷ 질량으로 구한다.
- 적분(잘게 쪼개서 더하기): "속도 × 짧은 시간"을 모두 더하면 이동 거리, "가속도 × 짧은 시간"을 더하면 속도 변화. 발사 계산에서 1/60초마다 더해 나간 것이 이것이다.
- 급수(컴퓨터 자릿수 한계를 피하는 근사): 컴퓨터는 실수를 16자리까지만 저장해, 느린 속도에서 두 시간을 그대로 빼면 차이가 사라진다. √(1 − β²)를 1 − β²/2 − β⁴/8 − … 로 바꾸어 빼기 없이 시간 차이 ≈ 지구 시간 × β²/2 로 구한다.

### 3. 발사 장면의 물리 계산 방법

등속 여행이면 이동 거리 = 속도 × 시간 한 줄로 끝난다. 그러나 발사 중인 로켓은 연료가 타면서 질량이 줄고, 고도가 오르면 중력이 약해지며, 기울어지면서 추력 방향이 바뀌고, 부스터가 떨어지면 질량과 추력이 한꺼번에 바뀌어 가속도가 매 순간 달라진다. 그래서 시간을 1/60초씩 잘게 자르고, 그 짧은 동안은 가속도가 일정하다고 보고 고등학교 물리의 등가속도 공식을 쓴다.

```
가속도       a = (추력 − 중력) ÷ 현재 질량       … 뉴턴 2법칙 F = ma
나중 속도    v = v₀ + a·Δt                        … Δt = 1/60초
총 이동 거리 s = s₀ + v·Δt                        … 지금까지 간 거리 + 이번 칸에 간 거리
질량         m = m₀ − 이번 칸에 탄 연료
```

이번 칸의 나중 속도가 다음 칸의 처음 속도가 되고, 이번 칸까지의 총 이동 거리가 다음 칸의 처음 거리가 된다. 발사부터 궤도 진입까지 약 500초, 즉 약 3만 번 반복한다. 매 칸의 위치와 속도가 3D 화면의 로켓 좌표와 HUD 숫자가 되고, 연료가 떨어지는 칸이 단 분리 시각, 원궤도 속도에 닿는 칸이 궤도 진입이다.

### 4. 탐구 과정에서 알게 된 것

1) 발사 과정을 재현하면서, 처음 속력에 "그 순간의 가속도 × 한 프레임(1/60초)"을 더하는 일을 계속 반복하면(적분하면) 현재 속력을 알 수 있다는 것을 알게 되었다.
2) 시간 지연은 "1초가 0.1초로 줄어드는 것"이 아니라 우주선 안에서는 시간 그 자체가 느리게 흐르는 것이며, 지구와 비교했을 때 비로소 차이가 드러난다는 것을 알게 되었다.
3) 웹에서 3D 물체는 Three.js 모듈로 표현하며, 기본 도형과 캔버스 텍스처만으로도 로켓·지구·우주선 내부까지 꽤 자세한 모델링이 가능함을 알게 되었다.
4) 시스템을 폴더별로 나누어 관리하고, AI에게 주는 프롬프트·코드·기능 설명을 따로 문서화하며, 계획부터 체계적으로 제시한 뒤 단계별로 구현하는 방식이 큰 프로그램을 끝까지 완성하는 데 효과적이었다.

## Ⅵ. 종합 결론

γ = 1/√(1 − β²) 한 줄의 식을 "지구 4.3년 동안 우주선 221일", "1년에 314일이 사라진다"처럼 생물 수명과 일상 속도에 견주는 표현으로 바꾸어 보여 주는 프로그램을 완성했다. 팔콘 헤비 제원에 뉴턴 운동 법칙을 적용해 실제 기록과 같은 자릿수의 분리·착륙 시각을 얻었고, 22개 단계·결정 97건·검증 125개를 문서로 남기며 약 9,700줄의 프로그램을 2주 남짓에 완성했다. 한계는 특수 상대성(속도 효과)만 다루고 공기 저항을 생략한 점이며, 앞으로 1g 가속-감속 모델과 중력 시간 지연(GPS 위성)을 더해 비교하고자 한다.
