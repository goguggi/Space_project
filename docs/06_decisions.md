물리 법칙이나 학술적 사실이 아닌 모든 결정은 사용자에게 묻고 여기에 기록한다.

## 2. 물리적 근거에 따라 정한 것 (사용자 확인 불필요)

| 번호 | 항목 | 내용 |
|---|---|---|
| P-01 | 발사장 위치를 거리 계산에 반영하지 않음 | 지구 지름(약 12,700 km)이 최단 목적지(달, 384,400 km) 대비 3%, 그 외 목적지에서는 0.01% 미만이므로 무시 |
| P-02 | 낮은 속도에서 테일러 급수 사용 | 배정밀도 실수의 유효숫자 손실 방지. [03_physics.md](03_physics.md) 3.1절 |
| P-03 | 1년 = 365.25일 | 율리우스년, IAU 표준 |
| P-04 | 발사 물리에서 지구 자전을 반영하지 않음 | 단순화. 자전에 의한 초기 속도(적도 약 0.46 km/s)는 공기 저항 생략(D-21)과 같은 수준의 근사 |
| P-05 | 피치 프로그램 지속시간 200초, 최종 85° | D-40의 "약 2분"을 실제 팔콘 헤비 제원으로 시험한 결과, 120초·88°는 2단 연소 전 추락. 200초·85°는 연소 종료 시 고도 약 490 km, 속도 약 11 km/s. `src/physics/launchDynamics.js` |
| P-07 | 착륙 연료가 예비 추진제(5%)를 초과해도 착륙 연소를 계속함 | 공기 저항 생략(D-21)으로 재진입 속도가 실제보다 커서 필요한 Δv가 예비량을 넘는다. 착륙은 항상 성공(D-41)이 우선이므로 초과분은 `propellantUsedForLanding`에 기록만 한다 |
| P-06 | 추력의 고도 보간 | T(h) = T_진공 − (T_진공 − T_해수면)·exp(−h/8,400 m). 대기압의 지수 감소에 따른 물리적 근사 |
