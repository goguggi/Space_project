# 06. 의사결정 기록과 미결 질문

물리 법칙이나 학술적 사실이 아닌 모든 결정은 사용자에게 묻고 여기에 기록한다.
개발 중 새로운 결정이 필요하면 "미결 질문"에 먼저 추가하고, 답을 받으면 "확정된 결정"으로 옮긴다.

## 1. 확정된 결정 (2026-09-05)

| 번호 | 항목 | 결정 | 비고 |
|---|---|---|---|
| D-01 | 플랫폼 | 웹 (HTML / JavaScript) | |

## 2. 물리적 근거에 따라 정한 것 (사용자 확인 불필요)

| 번호 | 항목 | 내용 |
|---|---|---|
| P-01 | 발사장 위치를 거리 계산에 반영하지 않음 | 지구 지름(약 12,700 km)이 최단 목적지(달, 384,400 km) 대비 3%, 그 외 목적지에서는 0.01% 미만이므로 무시 |
| P-02 | 낮은 속도에서 테일러 급수 사용 | 배정밀도 실수의 유효숫자 손실 방지. [03_physics.md](03_physics.md) 3.1절 |
| P-03 | 1년 = 365.25일 | 율리우스년, IAU 표준 |

## 3. 미결 질문 (구현 시작 전에 답이 필요함)

| 번호 | 질문 | 관련 단계 | 선택지 / 제안 |
|---|---|---|---|
| Q-01 | 스크립트 로딩 방식은? | 1단계 | A. 일반 `<script>` 태그 나열 (더블클릭 실행 가능) / B. ES 모듈 + 로컬 서버. 자세한 비교는 [02_architecture.md](02_architecture.md) 5절 |
| Q-02 | 속도 슬라이더 눈금 방식은? | 3단계 | 11.2 km/s ~ 0.99c는 약 27,000배 차이라 선형 눈금이면 슬라이더 대부분이 광속 근처가 됨. 제안: 로그 눈금 (왼쪽 절반이 km/s 영역, 오른쪽 절반이 광속 비율 영역) |
| Q-03 | 로런츠 인자 슬라이더를 직접 조작할 수 있게 할지? | 3단계 | A. 표시 전용 (속도 슬라이더에 연동되어 움직이기만 함) / B. 양방향 (γ를 움직이면 속도도 바뀜) |
| Q-04 | 스톱워치 애니메이션의 지속 시간과 시작 방식은? | 6단계 | 예: 결과와 무관하게 항상 5초 동안 올라감 / "출발" 버튼을 눌러야 시작 vs 입력 바꾸면 자동 시작 |
| Q-05 | 생존 여부 판정 시 출발 시점의 생물 나이는? | 7단계 | 제안: 출발 시점에 갓 태어난 것(나이 0)으로 가정하고, 경과 시간이 수명보다 짧으면 생존 |
| Q-06 | 막대 그래프를 어떤 방식으로 그릴지? | 7단계 | A. HTML/CSS의 div 막대 (구현 쉬움) / B. Canvas 직접 그리기 (자유도 높음). 두 경우 모두 외부 라이브러리 없음 |
| Q-07 | 가속-감속 모델의 가속도 입력 범위는? | 8단계 | 예: 0.1g ~ 10g 슬라이더, 기본값 1g |
| Q-08 | 스톱워치 표시 단위 구성은? | 6단계 | 사용자 표현 "0년 0분 0시"를 "년 / 일 / 시 / 분"으로 해석함. 초까지 표시할지, 백만 년 이상일 때 단위를 어떻게 줄일지 확인 필요 |
| Q-09 | 실제 탐사선 속도 프리셋 버튼(보이저, 파커 등)을 넣을지? | 3단계 | 요구사항에는 없음. 넣지 않는 것을 기본으로 함 |
| Q-10 | 하루살이 수명을 성충 기준 1일로 할지? | 7단계 | 유충 단계를 포함하면 수개월~2년으로 달라짐 |
