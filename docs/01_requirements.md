# 01. 요구사항 정리

작성일: 2026-09-05
이 문서는 사용자와의 대화에서 확정된 요구사항을 체계적으로 정리한 것입니다.
개발 중 요구사항이 바뀌면 이 문서를 먼저 고치고, 관련 코드를 수정합니다.

## 1. 프로그램의 목적

지구에서 출발한 우주선이 특정 천체까지 이동할 때,
**속도와 이동 거리에 따른 상대론적 시간 지연**을 계산하고,
그 결과를 **여러 생물의 수명**과 비교하여 시간 지연의 정도를 직관적으로 이해하게 한다.

## 2. 확정된 요구사항

### 2.1 플랫폼과 기술

| 항목 | 결정 |
|---|---|
| 플랫폼 | 웹 (HTML / CSS / JavaScript) |
| 외부 라이브러리 | 원칙적으로 사용하지 않음. 예외: 3D 발사 장면에만 Three.js 사용 (파일 동봉) |
| 사용자 인터페이스 | 처음부터 GUI (슬라이더, 선택 메뉴 등) |
| 언어 | 화면 텍스트, 코드 주석, 문서 모두 한국어 |
| 버전 관리 | Git. 원격 저장소 https://github.com/goguggi/Space_project.git |
| 실행 방식 | GitHub Pages(main 브랜치 루트)로 게시. 소스는 ES 모듈. 로컬 확인 시 로컬 서버 사용 |

### 2.2 출발 위치 (지구 상의 발사장)

- 사용자는 지구 상의 **발사장 5곳** 중 하나를 선택한다.
- 각 발사장은 이름, 국가, 위도, 경도를 가진다.
- 발사장 목록 (프리셋):
  1. 나로우주센터 (대한민국)
  2. 케네디 우주센터 (미국)
  3. 바이코누르 우주기지 (카자흐스탄)
  4. 기아나 우주센터 (프랑스령 기아나)
  5. 다네가시마 우주센터 (일본)
- 위도/경도 직접 입력, 지도 클릭은 **포함하지 않는다**.
- 참고: 천문학적 거리에 비해 지구 반지름은 무시할 수 있는 수준이므로,
  발사장 선택은 계산 결과에 사실상 영향을 주지 않고 표시와 연출 용도로 쓰인다.
  (자세한 근거는 [03_physics.md](03_physics.md) 참고)

### 2.3 목적지 (천체 12개, 목록에서만 선택)

| 구분 | 천체 |
|---|---|
| 태양계 (6) | 달, 화성, 목성, 토성, 해왕성, 태양 |
| 근처 별 (3) | 프록시마 센타우리, 시리우스, 베가 |
| 은하 규모 (2) | 오리온 성운, 은하 중심 |
| 은하 밖 (1) | 안드로메다 은하 |

- 임의의 거리를 직접 입력하는 기능은 **포함하지 않는다**.
- 행성과 지구의 거리는 **평균 거리 하나로 고정**한다. (공전 위치에 따른 변화는 무시)
- 각 천체의 거리 값과 출처는 [05_data_reference.md](05_data_reference.md)에 기록한다.

### 2.4 속도 조절

- 슬라이더로 속도를 조절한다. 눈금은 **로그 눈금**이다.
- **하한**: 팔콘 헤비의 지구 탈출 속도 약 11.2 km/s
- **상한**: 광속의 99% (0.99c)
- 속도에 대응하는 **로런츠 인자(γ)** 를 함께 슬라이더 형태로 표시한다. 표시 전용이며 직접 조작하지 않는다.
- **프리셋 버튼 6개**: 보이저 1호, 파커 탐사선, 0.1c, 0.5c, 0.9c, 0.99c. 누르면 슬라이더가 해당 속도로 이동한다.
- 임의 거리 입력이 없듯이, 속도도 슬라이더 범위 안에서만 조절한다.

### 2.5 여행 형태

- **편도 / 왕복**을 선택할 수 있다.
- 왕복은 편도의 2배로 계산한다. (등속 모델 기준)

### 2.6 운동 모델

1. **등속 비행 모델 (1차 구현)**: 출발 직후부터 지정 속도로 일정하게 비행한다고 가정한다.
2. **가속-감속 모델 (발사 시뮬레이션 뒤에 추가)**: 가속도 1g 고정으로 가속 후 감속하는 모델. 가속도 조절 슬라이더는 두지 않는다.

### 2.7 계산 결과

- 지구에서 흐른 시간, 우주선에서 흐른 시간, 두 시간의 차이를 계산한다.
- 계산은 프로그램이 직접 수행한다. (미리 계산된 표를 쓰지 않는다)

### 2.8 비교 생물 (5종)

| 생물 | 대표 수명 |
|---|---|
| 하루살이 | 약 1일 (성충 기준) |
| 개 | 약 13년 |
| 사람 | 약 80년 |
| 갈라파고스 코끼리거북 | 약 150년 |
| 그린란드 상어 | 약 400년 |

- 수명 값과 출처는 [05_data_reference.md](05_data_reference.md)에 기록한다.
- 사용자가 **생물별 출발 시점 나이**를 입력할 수 있다. (기본값 0)

### 2.9 결과 표시 방식 (4가지 모두 구현)

1. **스톱워치 애니메이션**: `0년 0일 0시 0분 0초`에서 시작하여 결과값까지 시간이 점점 올라가는 스톱워치 형태로 표시한다.
   지구 시간과 우주선 시간을 나란히 보여준다. 발사 장면이 끝나면 자동으로 시작하고, 결과가 길수록 오래(3~15초) 올라간다.
   100만 년 이상은 "만 년", "억 년" 단위로 표시한다.
2. **수치 표**: 지구 시간 / 우주선 시간 / 차이를 표로 표시한다.
3. **막대 그래프**: HTML/CSS 막대(로그 눈금)로 생물별 수명을 그리고, 그 위에 지구 시간과 우주선 시간을 겹쳐 그린다.
4. **생존 여부 아이콘**: 각 생물이 우주선 탑승 시 / 지구 잔류 시 도착 시점에 살아 있는지를 아이콘으로 표시한다.
   판정은 출발 나이 + 경과 시간이 수명보다 짧으면 생존이다.

### 2.10 3D 발사 시뮬레이션 (2026-09-05 추가)

- "발사" 버튼을 누르면 KSP처럼 **3인칭 시점의 3D 발사 장면**이 나오고, 카메라가 로켓을 따라간다.
- 로켓은 **팔콘 헤비형** (측면 부스터 2기 + 중앙 1단 + 2단)이며, 측면 부스터 → 중앙 1단 → 2단 순으로 분리된다.
- 분리된 단은 **스페이스X 방식으로 재착륙**한다. 측면 부스터 2기는 발사장 근처 착륙장, 중앙 1단은 바다 위 무인선. 2단은 회수하지 않는다.
- 로켓 움직임은 **단순 물리 시뮬레이션**(추력, 중력, 질량 변화)으로 계산한다. 공기 저항은 생략한다.
- 분리 후 **화면 분할**: 주 화면은 우주선, 작은 보조 화면은 착륙 장면.
- 발사 장면은 **1배~10배 배속**과 **건너뛰기**가 가능하며, 끝나면 스톱워치·결과 화면으로 전환된다.
- 자세한 계획은 [07_feature_plans.md](07_feature_plans.md) 기능 1 참고.

## 3. 개발 방식에 대한 요구사항

- 전체 기능을 한 번에 구현하지 않고, **초기 단계(출발 위치 지정)부터 순차적으로** 구현한다.
- **기능별로 파일을 분리**하고 체계적으로 관리한다.
- **각 폴더마다 md 파일 하나**를 두어 그 폴더의 코드를 설명한다.
- **전체 md 파일의 목차** md 파일을 별도로 관리한다. ([INDEX.md](INDEX.md))
- 새 기능을 계획할 때마다 **기능 계획 누적 파일** [07_feature_plans.md](07_feature_plans.md)에 하나씩 추가한다.
- 물리 법칙이나 학술적으로 규명된 내용 외의 **의사결정은 임의로 하지 않고 사용자에게 질문**한다.
  결정 내용은 [06_decisions.md](06_decisions.md)에 기록한다.

## 4. 범위 밖 (하지 않기로 한 것)

- 위도/경도 직접 입력, 지도 클릭 선택
- 임의 거리 직접 입력
- 출발 날짜 기준 실제 행성 거리 계산
- 한국어/영어 전환 기능
- 외부 그래프 라이브러리 사용 (3D 장면의 Three.js는 예외)
- 발사 장면의 공기 저항 계산
