## 기능 1. 3D 발사 시뮬레이션 (2026-09-05)

### 요청 내용

- 발사 시 KSP(Kerbal Space Program)처럼 **3인칭 시점에서 로켓 발사를 지켜보고, 카메라가 로켓을 따라간다.**
- 로켓은 **단 분리**를 하며, 분리된 단은 **스페이스X처럼 다시 착륙**한다.

### 확정된 결정

|---|---|---|
| D-19 | 표현 방식 | 3D |
| D-20 | 3D 라이브러리 | Three.js 허용. 파일을 `lib/three/`에 동봉하여 인터넷 없이 실행. (D-17 수정: "그래프는 직접 그리고, 3D만 Three.js") |
| D-21 | 로켓 움직임 | 단순 물리 시뮬레이션: 추력, 중력, 연료 소모에 따른 질량 변화. 공기 저항은 생략 |
| D-22 | 로켓 구성 | 팔콘 헤비형: 측면 부스터 2기 + 중앙 1단(코어) + 2단. 분리 순서는 측면 부스터 → 중앙 1단 → 2단 |

### 물리/계산 근거

[03_physics.md](03_physics.md) 6절에 정리했다. 요지는 다음과 같다.

- 운동 방정식: m(t)·dv/dt = T(방향) − m(t)·g(r), g(r) = GM/r²
- 질량 변화: dm/dt = −T / (Isp·g₀)
- 검증: 치올콥스키 로켓 방정식 Δv = Isp·g₀·ln(m₀/m_f)
- 착륙 연소 시작 고도: h = v² / (2·(a − g)) (일정 감속 가정)
- 시간 적분: 고정 시간 간격의 반음해 오일러(semi-implicit Euler) 또는 RK4. 배속은 한 프레임에 여러 번 적분하여 구현

**중요한 한계**: 2단 분리 직후 우주선의 실제 속도는 약 10 km/s 수준이다. 사용자가 슬라이더로 고른 속도(최대 0.99c)와는 맞지 않으므로,
발사 장면이 끝나는 시점에 "우주선이 지정 속도로 항해를 시작한다"고 보고 등속 모델([03_physics.md](03_physics.md) 2절)로 넘어간다.
발사 장면의 물리와 시간 지연 계산의 물리는 서로 독립이다.

## 기능 4: 실감 나는 임무 (18단계) — 기획안

사용자 요청 원문 (2026-09-12):

> 왕복할 때 지구에 재착륙하는것도 만들어주고, 출발과 도착하는 prograss bar의 각 부분을 클릭했을 때
> 그 장면이 바로 재생되게 해줘, 그리고 우주선이 올라가서 도킹되는 부분을 지루하지 않게 좀 짧게 만들어줘
> 또한 이 사진에서 변하는 것에 로런츠 인자 그래프(속력에 따라 연동)도 함께 넣어줘
> 또한 우주 여행 순간에서 1인칭으로 볼 때는 우주선 내부를 구현해주고, 그 안에서 창 밖을 내다보는 형식으로,
> 우주선을 약간 자신이 직접 조절할 수 있게 해줘 방향을
> 그리고 모든 행성은 거리에 비례하여 약 이동시간이 5초 ~ 1분으로 축약해주며,
> 착륙할 때 약간 임무처럼 ~펴기, ~펴기 할 수 있도록 약간 ksp프로그램처럼 만들어줘,
> 또한 발사장소에 지구 사진을 덧씌워 주며, 로켓을 조금더 현실감 있게 만들어줘

|---|---|---|

| R-2 | 진행 바 구간 클릭 재생 | 진행 바를 구간(발사·항행·도착 등)으로 나누고, 누르면 그 장면이 바로 재생된다 |
| R-3 | 발사~궤도 구간 단축 | 올라가서 우주선이 떨어져 나오기까지가 지루하다. 짧게 줄인다 |
| R-4 | 로런츠 인자 그래프 | 속도에 따라 γ가 어떻게 커지는지 곡선으로 보여 주고, 지금 속도를 곡선 위에 표시한다 |
| R-5 | 1인칭 = 우주선 내부 | 조종석 안에서 창 밖을 내다보는 시점 |
| R-6 | 방향 직접 조종 | 우주선의 바라보는 방향을 사용자가 돌린다 |
| R-7 | 이동 시간 5초~1분 | 모든 목적지의 재생 시간을 거리에 비례해 5초~1분 사이로 맞춘다 |
| R-8 | KSP식 착륙 임무 | 착륙 중 "착륙 다리 펴기", "감속 연소" 같은 절차를 사용자가 직접 수행한다 |
| R-9 | 발사장 지구 사진 + 현실감 있는 로켓 | 발사장 주변에 실제 지구 모습을 입히고, 로켓 형상을 더 사실적으로 |

## 기능 5: 우주인 탐사와 실전 착륙 (20단계) — 기획안

사용자 요청 원문 (2026-09-13):

> 내려서 우주인이 되어 임무(탐사)도 할 수 있는것도 추가해줘, 그리고 ksp처럼 착륙 실패하면 터지는것도
> 또한 탐사선(우주 항행할때) 좀더 개쩔게 만들어주고, 탐사선 안의 구조도 재현해서
> 안에서 우주선 밖과 우주선 안을 볼 수 있게 해줘

| 번호 | 요청 | 구현 방향 |
|---|---|---|
| S-1 | 착륙 후 우주인 탐사(EVA) | 접지에 성공하면 우주인이 내려 지표를 걸어 다닌다. 깃발 꽂기·샘플 채집·사진 촬영·복귀 임무 |
| S-2 | 착륙 실패 시 폭발 | 접지 속도가 한계를 넘거나 다리를 안 폈으면 파손·폭발. "다시 시도"로 재도전 |
| S-3 | 탐사선 형상 개선 | 항행 중 보이는 우주선을 실제 심우주 탐사선처럼: 기밀 모듈·태양전지판·고이득 안테나·방열판·도킹 포트 |
| S-4 | 탐사선 내부 재현 | 1인칭에서 조종석뿐 아니라 선내(좌석·콘솔·해치·수납·측면 창)를 둘러본다. 창밖도 함께 보인다 |

**중요한 방침 변경**: S-2는 기존 결정 D-41(착륙은 항상 성공)·D-67(놓쳐도 등급만 낮아짐)과 충돌한다.
사용자가 명시적으로 요청했으므로 **목적지·지구 착륙에 한해** 실패를 도입한다 (D-75).
부스터·코어 회수(13단계)는 자동 유도이므로 기존대로 항상 성공을 유지한다.

세부 스펙은 아래 20단계 항목과 [06_decisions.md](06_decisions.md) D-75~D-79에 있다.

## 기능 6: 연출 다듬기 (21단계) — 기획안

사용자 요청 원문 (2026-09-13):

> 이제 지구에 nasa 사진을 덧붙이고, 인터스텔라 bgm으로 바꿔, 교육용으로 쓸꺼라 저작권 상관없어
> 또한 로켓이 출발할때 실제 로켓이 출발하는것처럼 화염이 나오게 해주고,
> 프로그래스바가 잘잘잘 올라가게 해줘 지금처럼 14퍼 29퍼 1방에 가는게 아니라

| 번호 | 요청 | 구현 방향 |
|---|---|---|
| T-1 | 지구에 NASA 사진 | 사진이 있으면 입히고 없으면 사실적으로 다시 그린 캔버스 지구를 쓴다 (D-87, D-88) |
| T-2 | 인터스텔라 BGM | **원곡은 쓸 수 없다.** 저작권이 있는 곡은 저장소에 넣을 수도, 코드로 복제할 수도 없다(교육용도 예외가 아니다). 같은 결의 자작 곡으로 바꾸고, 직접 고른 음원을 틀 수 있는 단추를 둔다 (D-89) |
| T-3 | 실제 같은 발사 화염 | 화염을 네 겹 + 마하 디스크 + 발광 + 실제 조명으로. 발사대 연기 구름 추가 (D-91) |
| T-4 | 연속으로 오르는 진행 막대 | 이정표 사이를 예상 시각으로 비례 배분 (D-90) |

T-2는 사용자 요청과 다르게 구현한 유일한 항목이다. 이유: 저작권은 사용 목적이 교육이라도 자동으로 면제되지 않는다.
대신 (1) 분위기가 비슷한 자작 곡을 만들고, (2) 발표 때 원하는 음원을 직접 틀 수 있게 파일 선택 기능을 넣었다.
