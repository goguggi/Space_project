# src/audio/ — 소리

배경 음악과 효과음을 **코드로 만들어** 연주한다 (17단계, D-59).

## 규칙

- **음원 파일을 두지 않는다.** 기성곡은 저작권 문제로 넣을 수 없고, 이 저장소는 외부 자산을 쓰지 않는다.
  Web Audio API의 오실레이터와 잡음만으로 만들면 `열기.html`(오프라인)에서도 그대로 울린다.
- 화면(DOM)을 다루지 않는다. 음소거 버튼 같은 조작 요소는 `ui/`에 둔다.
- 물리 계산도 하지 않는다. `main.js`가 장면과 추력을 알려 주면 그에 맞춰 소리만 낸다.
- 브라우저는 사용자가 한 번 누르기 전에는 소리를 내지 못한다. 그래서 `resume()`을 버튼에서 부른다.

## 현재 파일 목록

| 파일 | 내보내는 것 | 설명 |
|---|---|---|
| `spaceAudio.js` | `createSpaceAudio()` | 장면별 우주 앰비언트와 효과음. `resume()`, `setEnabled(on)`, `setMood(name)`, `setEngine(0~1)`, `thud()`, `chime()`, `boom()`, `isOn()` |

## 음악이 만들어지는 방식

1. **지속음(드론) 두 겹** — 근음과 5도. 아주 느린 흔들림(LFO)을 걸어 넓게 퍼지는 소리를 만든다.
2. **반짝임** — 5음 음계(펜타토닉)에서 고른 음을 불규칙한 간격으로 하나씩 띄운다. 종소리처럼 감쇠하고 좌우로 벌어진다.
3. **장면 분위기** — `ready` / `launch` / `cruise` / `landing` / `arrived` 마다 근음, 음계, 필터 밝기, 음이 뜨는 빈도가 다르다. 바뀔 때는 2.5초에 걸쳐 옮겨 간다.

## 효과음

| 함수 | 소리 | 쓰는 곳 |
|---|---|---|
| `setEngine(level)` | 갈색 잡음을 저역 통과로 거른 지속음. 추력이 크면 커지고 밝아진다 | 발사·착륙 연소 |
| `boom()` | 낮고 긴 울림 | 발사 순간 |
| `thud()` | 짧은 충격음 | 단 분리, 접지 |
| `chime()` | 화음 네 음이 차례로 | 목적지 도착 |
