# src/audio/ — 소리

배경 음악과 효과음을 **코드로 만들어** 연주한다 (17단계 D-59, 21단계 D-89에서 곡을 다시 씀).

## 규칙

- **음원 파일을 두지 않는다.** 기성곡(영화 음악 포함)은 저작권 문제로 넣을 수 없고 — 교육용도 예외가 아니다 —
  이 저장소는 외부 자산을 쓰지 않는다. Web Audio API의 오실레이터와 잡음만으로 만들면 `열기.html`(오프라인)에서도 그대로 울린다.
- 발표 때 특정 곡을 쓰고 싶으면 화면의 "🎵 내 음악" 단추로 자기 파일을 고른다. 그 파일은 **브라우저 안에서만** 재생되고
  저장소에는 들어가지 않는다 (`useCustomTrack(file)` / `clearCustomTrack()`).
- 화면(DOM)을 다루지 않는다. 음소거 버튼 같은 조작 요소는 `ui/`에 둔다.
- 물리 계산도 하지 않는다. `main.js`가 장면과 추력을 알려 주면 그에 맞춰 소리만 낸다.
- 브라우저는 사용자가 한 번 누르기 전에는 소리를 내지 못한다. 그래서 `resume()`을 버튼에서 부른다.

## 현재 파일 목록

| 파일 | 내보내는 것 | 설명 |
|---|---|---|
| `spaceAudio.js` | `createSpaceAudio()` | 장면별 배경음과 효과음. `resume()`, `setEnabled(on)`, `setMood(name)`, `setEngine(0~1)`, `setTimeDilation(γ)`, `useCustomTrack(file)`, `clearCustomTrack()`, `hasCustomTrack()`, `thud()`, `chime()`, `boom()`, `isOn()` |

## 음악이 만들어지는 방식 (21단계, D-89)

1. **오르간 지속화음** — 근음·5도·옥타브를 각각 배음 6개(1·2·3·4·6·8배)로 쌓아 파이프 오르간처럼 두껍게 낸다.
   음마다 조금씩 어긋나게(디튠) 두고 느린 흔들림을 걸어 여러 파이프가 함께 우는 소리를 만든다.
2. **오스티나토** — 8분음표로 오르내리는 짧은 음형을 계속 반복한다. 장면마다 음형이 다르다.
3. **시계 초침** — 두 박자에 한 번 아주 짧은 딸깍. **γ(시간 지연)에 비례해 느려진다**(`setTimeDilation`, 최대 8배).
   우주선이 빨라질수록 음악이 늘어지는 것을 귀로 듣게 하려는 장치다.
4. **장면 분위기** — `ready` / `launch` / `cruise` / `landing` / `arrived` 마다 근음, 빠르기(bpm), 오르간 세기, 음형이 다르다.
   바뀔 때는 2.5초에 걸쳐 옮겨 간다.

## 효과음

| 함수 | 소리 | 쓰는 곳 |
|---|---|---|
| `setEngine(level)` | 갈색 잡음을 저역 통과로 거른 지속음. 추력이 크면 커지고 밝아진다 | 발사·착륙 연소 |
| `boom()` | 낮고 긴 굉음 + 오르간이 함께 부풀어 오른다 | 발사 순간, 착륙 실패 |
| `thud()` | 짧은 충격음 | 단 분리, 접지 |
| `chime()` | 화음 네 음이 차례로 | 목적지 도착 |
