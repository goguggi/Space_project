# 우주여행 시간 지연 계산기

지구의 발사장에서 출발한 우주선이 태양계 또는 우주의 특정 천체까지 이동할 때,
속도와 이동 거리에 따라 발생하는 **상대론적 시간 지연**을 계산하고,
그 결과를 **여러 생물의 수명**과 비교하여 직관적으로 보여주는 웹 프로그램입니다.

- 플랫폼: HTML / CSS / JavaScript (3D 발사 장면에만 Three.js 사용, 그 외 외부 라이브러리 없음)
- 언어: 화면, 주석, 문서 모두 한국어
- 버전 관리: Git
