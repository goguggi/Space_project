# tests/ — 계산 검증

`src/physics/`의 함수가 [docs/03_physics.md](../docs/03_physics.md) 5절의 기준값과 일치하는지 확인한다.
외부 테스트 도구 없이, 브라우저에서 여는 HTML 페이지 형태로 만든다.

## 예정 파일

| 파일 | 내용 | 추가 단계 |
|---|---|---|
| `physics.test.html` | 기준값 표를 화면에 출력하고, 계산값과 비교하여 통과/실패 표시 | 4단계 |

## 실행 방법

로컬 서버를 띄운 뒤 `http://localhost:8000/tests/physics.test.html` 을 연다. 메인 화면 아래쪽 링크로도 열 수 있다.

## 현재 파일 목록

| 파일 | 내용 |
|---|---|
| `physics.test.html` | 검증 결과 표를 보여주는 페이지. 상단에 "N / N 통과" 요약 |
| `physics.test.js` | 검증 항목 26개. 시간 지연 13개: γ 기준값 5개, 급수/직접 계산 경계 연속성, 프록시마·달 편도 시간, 왕복 = 편도 × 2, 차이 정밀 계산 일치. 발사 물리 6개: 중력 없는 1단 로켓의 Δv = 치올콥스키 값, 팔콘 헤비 부스터·코어 분리 시각이 실제 기록의 ±15%, 2단 종료 고도 ≥ 200 km·속도 ≥ 7.8 km/s, 추락 없음. 재착륙 7개: 부스터·코어 착륙 성공, 접지 속도 ≤ 3 m/s, 착륙 위치(착륙장 2,000 m ±50, 무인선), 모든 회수 단 접지. 항목마다 상대 허용 오차를 둔다 |

새 계산 함수를 추가하면 여기에 검증 항목을 함께 추가한다.
